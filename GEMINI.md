# Project Guidelines

## Git & GitHub
- **NEVER** push to GitHub without an explicit, direct instruction from the user for the **current** task.
- A previous instruction to push does **NOT** apply to future tasks.
- Always ask for permission before pushing, even if the work is complete.
- Local commits are encouraged, but remote pushes are strictly restricted.

## Engineering Standards
- Follow the plan-research-execute cycle.
- Prioritize TDD and thorough validation.
- Maintain idiomatic Dart/Flutter code.
